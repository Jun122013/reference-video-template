# 媒体查看与可选工具

> 作者：胡峻  
> Copyright © 2026 胡峻。保留所有权利。

核心分析和写提示词不依赖脚本、API 或其他 Skill；需要宿主能查看用户提供的视频/图片。音频判断还需要真实听音能力。没有这些能力时必须说明观察范围。

## 有视频理解或播放器

直接查看完整片，再回到关键时间点。长片可分段检查，但所有分段需覆盖并注明接缝；不要用摘要代替未看内容。

## 本地已安装 FFmpeg / FFprobe

以下是可选命令示例，先确认工具存在；不自动安装大型依赖。替换输入路径，输出放单独案例目录。示例输出文件已存在时 `-n` 会停止，不覆盖源文件。

媒体信息：

```bash
ffprobe -v error -show_format -show_streams -of json "input.mp4"
```

逐帧时间用于 VFR 或关键时间核对（长片输出可能较大，保存到项目文件再按需读取）：

```bash
ffprobe -v error -select_streams v:0 -show_frames -show_entries frame=best_effort_timestamp_time,pkt_duration_time -of json "input.mp4"
```

粗看画面，先创建名为 frames 的输出目录：

```bash
ffmpeg -n -i "input.mp4" -vf "fps=2,scale=640:-2" "frames/overview_%05d.jpg"
```

这些是每秒两张的采样图，不是源帧号，可能漏掉短事件。重要变化用全帧或指定时间段检查。

精确取一个源解码帧（例为第120帧，从0计；不是第120秒）：

```bash
ffmpeg -n -i "input.mp4" -vf "select=eq(n\,120)" -frames:v 1 "frame_120.png"
```

若输入有音轨，提取第一音轨供听审；此文件不是自动分离人声/伴奏：

```bash
ffmpeg -n -i "input.mp4" -map 0:a:0 -vn -c:a pcm_s16le "reference-audio.wav"
```

以上工具只提取信息和媒体，不能自己得出审美或听感结论。未经连续查看，不报告“全片无掉帧”；没有听音，不报告“原曲相同且卡点”。

## 链接受限或没有本地工具

使用当前宿主支持的浏览/下载能力；平台要求登录时不要尝试绕过访问限制。请用户直接提供原视频是有效替代。若用户只能提供截图，可交付截图范围内的构图分析与暂定提示词，明确节奏、动作连续性和声音未验证。

## 可选生成

本包不附账号、密钥、收费服务或固定 API 适配器。可将实例 Prompt 粘贴到所选视频工具，或调用宿主已配置的接口。先核对该工具真实的模型、模式、参考类型和规格，沿用用户预算。没有接口时交付完整提示词包即可，不能声称已生成视频。
