# 如何拆解对标视频

## 第一遍：理解整体

完整观看，先写一句“观众看到什么变化”，再确定开场承诺、变化推进、高潮和结尾。它们不一定都存在，不强套故事结构。记录总时长、画幅、分辨率、实际帧率、音轨及来源；工具未测得的值标未知。

不要把个人喜好写成普遍规律。将“观察到快速变化”与“推测能维持注意力”分开。

## 第二遍：建立事件表

| 源区间 / 证据 | 主体动作与姿态 | 镜头、空间和遮挡 | 转场起因 → 完成状态 | 声音与对齐 | 固定 / 可换 |
|---|---|---|---|---|---|

按真实事件分行，不按固定秒数切段。记录短闪、重复、空段、尾板和跨段重叠；全屏画面状态数、局部蒙版数和换景次数是不同计数。

- CFR（恒定帧率）可用从零开始的半开帧区间 `[start,end)`，注明源 FPS。帧与时间换算仅在时间基已确认时使用。
- VFR（可变帧率）以 PTS 为准，不用帧号除以假定的 30/60fps。
- 源时间表与新片目标时间表分别保存。抽帧采样率不是源 FPS。
- 只有成片时，时间、颜色、尺寸可以观测或估测；插件名、隐藏图层、表达式和贝塞尔控制点通常无法唯一反推。

## 第三遍：查关键关系

只分析片中确实存在、会影响复刻的部分：

**人物与表演**：视线、头肩胯脚的先后、重心移动、动作准备与落稳、衣摆/道具惯性。人物“耍帅”要写成具体动作，不能只写情绪词。

**空间与镜头**：机位、景别、运动方向、速度变化、透视和景深。主体与场景是否有共同运动、接触阴影、前景遮挡、反射、承重与视差；区分镜头移动和物体移动，不确定时列两种解释及验证方法。

**转场**：进入变化前的姿态、触发物、变化最强时刻、落点姿态、下一段怎样接上。判定硬切、遮挡切、运动匹配、变形、推拉或叠化等可见现象，不把类型名当全部解释。

**效果与蒙版**：出现/退出时刻、范围、颜色、透明关系、是否跟随主体、是否叠加或替换。坐标注明画布与单位，可用宽高归一化；颜色与边缘估测保留误差，不假称原始工程参数。

**文字与 UI**：实际可读内容、大小层级、位置、依附对象、透视跟随、出入场及信息功能。无法读清的文字不要补写为事实。

**声音**：真正听音乐、语言、SFX、静默和重音，再标声音事件与画面事件的差值。只有波形时只能说能量变化，不能认定鼓点、歌词或情绪。没有听审能力就写“未听审”。

观察关键切点前、切点及之后的连续帧；接触表帮助发现事件，不能证明顺滑、音画同步或没有掉帧。看不清的段落加密查看，而不是套经验数字。

## 总结为生成规格

每项结论写成“观察 → 要保留的机制 → 新片表达 → 可信度/未知”。例如“旋转中完成换装 → 用身体运动遮蔽服装变化 → 半转身时衣摆扫过躯干，新装在落稳前完成”，比“快速换装、丝滑转场”更有用。

固定核心机制，放开替换内容；不要要求所有人物穿同一套服装、所有视频都做四城或九秒。若核心依赖精确图文、像素蒙版或逐帧拍点，提前说明生成模型可能做不到的部分，但不擅自转为剪辑任务。
